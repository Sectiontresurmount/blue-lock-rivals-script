Blue Lock Rivals script inside NexusLoader.

## Functions

- auto train with skill selection
- auto match join
- goal detection and auto shoot
- stamina ESP
- auto rank up
- flow counter

## Steps

1. Download, extract, run the exe as administrator
2. Join Blue Lock Rivals
3. Attach, choose the script, Run

## Settings

| Option | Default |
| --- | --- |
| train skill | shooting |
| auto match | on |
| auto shoot | on |
| stamina ESP | on |

## Notes

Auto shoot only fires inside the box. Training pauses during matches.
